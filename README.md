# Caarl Dev — Portfólio Roblox

Portfólio estático responsivo em português, com galeria dos oito projetos na ordem enviada, especialidades, apresentação e contato.

## Publicar na Vercel
Conecte `Z3ROREIGN/Caarldev.online`. Framework preset: **Other**. Build command e install command vazios. Output directory: `.`.

Arquivos: `index.html`, `style.css`, `script.js` e `assets/` com as oito imagens WebP.
