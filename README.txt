PORTFÓLIO CAARLDEV
==================
Como usar: dê dois cliques em index.html (precisa de internet só para carregar as fontes).

Arquivos:
- index.html  -> conteúdo
- style.css   -> visual
- script.js   -> formulário e ano do rodapé
- assets/fundo.gif -> GIF do fundo

Como colocar seus trabalhos na seção "Trabalhos":
No index.html, dentro de cada <div class="work-media">, adicione por exemplo:
  <img src="assets/meu-trabalho.jpg" alt="Descrição" style="width:100%;height:100%;object-fit:cover;border-radius:8px">
ou um <video src="assets/meu-video.mp4" controls></video>.
